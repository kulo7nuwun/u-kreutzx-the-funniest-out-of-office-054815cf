# The Funniest Out-of-Office

Entry for the [make.fun competition](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf): one line of an out-of-office auto-reply, the funniest it can be, in 140 characters or fewer.

## The line

> I'm out of the office until Monday. If it's urgent, please panic quietly among yourselves — I've left my stress with you as a souvenir.

It works as a real auto-reply — it says when I'm back — and the joke lands on the handover: the panic and the stress now belong to the reader, gift-wrapped as a souvenir.

## Run

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (creating `/output` if needed) and checks first that the line is 1–140 characters and not only white space, mirroring the competition gate.
